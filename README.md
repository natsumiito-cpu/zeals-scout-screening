# zeals-scout-screening

# スカウト自動判定ツール プロンプト管理リポジトリ

このリポジトリは、Googleスプレッドシートの採用判定AI（Gemini関数）が読み込むための指示文（プロンプト）を管理しています。

## 📁 ファイル構成
- `ai_consultant_prompt.txt` ：AIコンサルタント職の求人票および判定プロンプト

## 💡 判定基準（求人票）を変更したい場合の手順
AIコンサルタントの必須スキルや求める人物像が変わった場合は、以下の手順で修正してください。

1. このリポジトリにある `ai_consultant_prompt.txt` の内容を直接書き換えて保存（Commit）します。
2. スプレッドシート側は、このファイルの最新版をネット経由で自動的に読みにいく仕組み（IMPORTDATA関数）になっています。
3. そのため、**スプレッドシート側の数式や設定をいじる必要はありません。** GitHub側を更新するだけで、全メンバーのスプレッドシートに最新の判定基準が自動反映されます。

## ⚠️ 注意点（エンジニア向け）
スプレッドシート側では、このファイルの「Raw URL」を使って読み込みを行っています。
万が一、ファイル名（`ai_consultant_prompt.txt`）を変更したり、リポジトリを削除したりするとスプレッドシート側のAIが動かなくなるため注意してください。
